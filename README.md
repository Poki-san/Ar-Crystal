# ECHO WEAR

Flutter-прототип приложения генеративной NFT-одежды по ТЗ из `ТЗ.txt`.

## Что реализовано

- коллекция созданных цифровых вещей;
- демонстрационный сценарий «захват текстуры и звука → выбор силуэта → кристаллизация»;
- процедурный кристаллический принт для футболки, худи, платья и кед;
- карточка объекта и демонстрационный AR-интерфейс;
- локальный каталог маркетплейса с фильтрами;
- профиль, кошелёк, прогресс и локальные статусы;
- Android 8+ и iOS 15.5+ (ограничение актуального ML Kit Pose Detection).

Проект намеренно не содержит бэкенда, реальных транзакций и тестов. Камера, запись звука, локальное выделение палитры, сохранение коллекции и базовая AR-примерка работают на устройстве без сервера. Для проверки камеры и ML Kit нужен физический Android/iOS-телефон.

## Запуск

```bash
flutter pub get
flutter run
```

Статическая проверка:

```bash
flutter analyze
```
